# Alcohn AI

Aplicación web moderna construida con Next.js, Supabase y Tailwind CSS.

## Tecnologías

- [Next.js](https://nextjs.org/) - Framework de React
- [Supabase](https://supabase.com/) - Backend as a Service
- [Tailwind CSS](https://tailwindcss.com/) - Framework de CSS

## Configuración del Proyecto

1. Clona el repositorio:
```bash
git clone https://github.com/madwin2/Alcohn-Ai.git
```

2. Instala las dependencias:
```bash
npm install
```

3. Crea un archivo `.env.local` y configura las variables de entorno:
```
NEXT_PUBLIC_SUPABASE_URL=tu_url_de_supabase
NEXT_PUBLIC_SUPABASE_ANON_KEY=tu_clave_anonima_de_supabase
```

4. Inicia el servidor de desarrollo:
```bash
npm run dev
```

## Características

- App Router de Next.js 14
- Integración con Supabase para la base de datos
- Diseño responsivo con Tailwind CSS
- TypeScript para un desarrollo más seguro
